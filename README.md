# MySQL College Library Management System

## 📌 Project Overview
This project demonstrates a College Library Management System using MySQL. It focuses on managing student details, book records, and library-related information using SQL queries.

## 🛠️ Technologies Used
- MySQL
- MySQL Workbench
- SQL

## 📚 Concepts Covered

1. Database Creation
2. Table Creation
3. INSERT INTO
4. SELECT
5. WHERE Clause
6. UPDATE
7. DELETE
8. INNER JOIN
9. LEFT JOIN
10. RIGHT JOIN
11. FULL OUTER JOIN (using UNION)
